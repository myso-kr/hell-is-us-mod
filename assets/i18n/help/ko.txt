hiumod — Hell Is Us(Steam)용 싱글 플레이 치트·미니맵

사용법
  hiumod                        필요하면 게임을 켜고 패널을 엽니다 — ` (~) 로 보이기/숨기기;
                                게임이 꺼지면 패널도 닫힘
  hiumod ui                     패널만; 게임은 켜지 않음
  hiumod doctor                 모든 것을 점검; 아무것도 쓰지 않음
  hiumod doctor inspect <대상> [깊이] [gaps]
                                살아 있는 객체의 모든 반사 필드를 이름과 값으로;
                                포인터는 `깊이` 단계까지 따라감 (기본 0);
                                `gaps` 는 필드 사이의 네이티브 바이트도 보여 줌
  hiumod doctor find <텍스트>   이름에 텍스트가 든 모든 클래스·구조체 속성
  hiumod doctor dump [접두사]...
                                이름이 접두사로 시작하는 클래스·구조체의 SDK 식 목록
                                (기본 Charlie, Story)
  hiumod doctor usmap           불러온 클래스·구조체·열거형을 .usmap 매핑 파일로
                                (tools/survey 용)
  hiumod doctor survey [월드]   매핑, 그다음 게임 지도에 tools/survey:
                                모든 월드가 주는 것을 Mods\survey 로 —
                                그리고 게임의 12개 언어 텍스트
  hiumod doctor locale          게임 텍스트만 Mods\locale 로: 아이템·NPC·지역 이름을
                                게임 언어로
  hiumod doctor saves [s]       메모리의 모든 세이브 객체를 5초마다: 날짜·사실·
                                끝난 선행 — 플레이 중 게임이 어느 것을 갱신하는지
  hiumod doctor watch <대상> [초]
                                객체에서 바뀌는 것 (이름 있는 필드든 네이티브든) 을 바뀔 때마다
  hiumod doctor scan <대상> <값>
  hiumod doctor scan next <값>
                                객체에서 값이 있는 곳; 게임에서 값이 바뀐 뒤엔
                                그중 함께 바뀐 곳
                                대상: hero, controller, asc, sets, inventory, items,
                                save, world, enemy[:N], 0x주소, 또는 클래스 이름[:N]
                                — 결과는 Mods\doctor 에도 저장
  hiumod list                   모든 세트의 모든 속성을 실시간으로
  hiumod get <속성>...          그중 일부, Name 또는 Set.Name 으로
  hiumod pose                   주인공의 위치와 방향, Ctrl+C 까지 실시간으로
  hiumod set <치트> <값>        한 번 쓰는 값 (아직 표에 없음)
  hiumod hold <치트>...         예: god stamina speed=2 — Ctrl+C 까지;
                                유지할 수 있는 치트는 `hiumod doctor` 목록에 있음
  hiumod restore                강제 종료된 hold 가 바꿔 둔 것을 되돌림

옵션
  --game-dir <폴더>             HellIsUs\ 가 든 설치 폴더
                                (기본: Steam 라이브러리에서 찾음)

주인공을 조작하는 동안에만 값을 씁니다. 세이브를 백업해 두세요.
