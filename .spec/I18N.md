# Internationalization (i18n)

The mod follows **the game's text language setting**. Changing the language in the game's options
switches the mod within a few seconds.

## 1. Language detection

- Source: `TextCulture` (StrProperty, e.g. `ko`) in
  `%LOCALAPPDATA%\HellIsUs\Saved\SaveGames\HellIsUsProfile.sav`. `AudioCulture` is the voice language
  and is separate. The setting is not in `GameUserSettings.ini`.
- `i18n::follow_game()` (`src/i18n/mod.rs`) runs once when the panel starts, then every 2 s on the
  backup thread. The file is re-read only when its modification time changes.
- The game offers 12 cultures: de, en, es, fr, it, ja, ko, pl, pt-BR, ru, tr, zh-Hans. For a culture
  without a table the language part is tried (`pt-BR` → `pt`), then English.

## 2. Game proper nouns (items, NPCs, regions): the game's own translations

- `hiumod doctor locale` (also run automatically at the end of `doctor survey`) calls tools/survey
  `--locale`, which writes:
  - `Mods\locale\<culture>.tsv`: every entry of the game's locres as `namespace \t key \t text`
    (~6,700 lines per language; `\n`, `\t`, `\` escaped).
  - `Mods\locale\names.tsv`: which text names what.

    | Kind | id | Source |
    |---|---|---|
    | item | data asset name (lowercase) | `ItemData.Name` of `Items/**/*_DA` (for a string table, that table's namespace) |
    | npc | blueprint class (lowercase) | quick chat: `QuickChatSubjectPersistenceRuneComponent.Rune.SpeakerInfos.SpeakerName`; conversation: `ConversationRuneComponent.Rune.NamePayload.ContainedFacts[0]` → StringFactData.Description |
    | name | name fact asset | `Track=Name` StringFactData in StoryUnits (real names etc., per story unit) |
    | region | world | `Facts_Shared / Universal_Location_<World>` |

  - `Mods\locale\facts.tsv` (2026-10-03, the clue board): every `StringFactData` with a
    `Description` under `GameData/StoryUnits/<unit>/` and `GameData/Quests/<quest>/`, as
    `fact \t asset \t namespace \t key \t unit \t Track \t category` — the category is the last part
    of `UICategory` (`Quest.UI.FactCategory.Connections` → `Connections`; also `Description`,
    `Location`, `Quest`, `Name`, `WorldZone`). 887 facts; 881 have Korean text.
  - The locres namespace of string-table text is **the table's TableNamespace**, not the TableId path
    (`Items_Secrets_ST` → `Secrets_Items`).
  - All of these are game data and are not committed. A locale without `facts.tsv` (made before it
    existed) is read again by the panel (`gamedata::needed`).
- **NPC names:** the name shown at first meeting (e.g. "Sheltered Mechanic"), switching to the real name
  once the hero learns that story unit's real-name fact (`i18n::set_known`, called when the engine
  reads knowledge).
- **Quest clue branches** (`Quest01_Tania` etc.): the tail of the branch name is the story unit; the
  most specific name fact the hero knows is used (real name first). If none is known, the alias the
  game first shows (Dummy/Unknown) is used, so real names are never revealed early. Places, which have
  only one name, use it.
- **Good deed and mystery titles, places:** text the game has not shown yet comes out as the string
  table's English source. It is looked up by the same key in the English locres and shown in the
  current language (`i18n::from_source`, namespaces `UI_Secrets` and `Facts_*`).
- Survey points that give no item (only facts or tags) have no name in the game; they are labelled
  "Place to examine" (`PLACE_TO_EXAMINE`).
- Zero-width spaces (U+200B) in Japanese text are removed.
- Without locale data (no survey run), names are built from class names (`goals::pretty`,
  `goals::item_label` in `src/guide/goals.rs`).
- Quest names come from the game's in-memory FText (already in the current language). The quest cache
  is per language: `quests.<culture>.txt`, with Korean keeping the original `quests.txt`
  (`src/guide/quests.rs`).

## 3. The mod's own text

- Code refers to text by **key**, in English UPPER_SNAKE: `tr!("NEXT_GOAL")`,
  `trf!("NEEDED_HERE", h = here)`. Korean is a table like any other, `assets/i18n/ko.tsv` (switched
  2026-10-03; before that the Korean sentence itself was the key).
  - Keys are derived from the English sentence (its first few words), made more specific when meanings
    collide: `DEADLINE_JUDITH_BABY`, `GATE_CLOSED_WHY`, `CHEATS_ON_COUNT`.
  - `trf!` names every value, so a translation can reorder them. Filled at run time by `i18n::fill`
    (`src/i18n/fill.rs`): `{name}` and `{name:spec}` (fill, alignment, width, precision).
  - Text in const tables (cheat names, collectible categories) is also a key, translated on display
    with `i18n::tr(c.label)`.
  - Proper nouns inside text (regions, characters, keystones) are never written out; they are
    `{g:namespace/key}` tokens filled from the game's text in the current language. Example:
    `{g:Facts_Shared/Universal_Location_Talju}` → 탈주 / Talju / タルジュ (the Korean, English and
    Japanese game text). Translations keep the same token.
  - Text in data tables (the to-do column of `assets/missables.tsv`) is also keyed, translated and
    filled with `i18n::text()`.
  - Status and error messages (game connection, gate, cheat commands) and the CLI output shown in the
    console work the same way. The CLI also follows the game language at startup.
  - Help (`help`) is a per-language file, `assets/i18n/help/<culture>.txt` (12 files).
  - Only the log file (`hiumod.log`) stays in English; it is a development record.
- **Tables:** `assets/i18n/<culture>.tsv`, one `KEY \t text` line per key (`\n`, `\t`, `\\` escaped),
  compiled into the program (`TABLES` in `src/i18n/text.rs`, 12 entries).
  - English is written directly; the others were translated using each language's official game
    terms (Lymbic, keystone, good deed, region names, etc.) looked up in `Mods\locale`.
  - Terms that needed checking: APC (the game's own term per language, e.g. VAB, БТР, ZPT), Secret,
    crafting tome, and names the game does not have (e.g. the Vyssa mine).
  - Lookup order: the game language's table → English → the key itself. Before the game language has
    been read, Korean (`culture::DEFAULT` = `ko`).
- **Tests** (`src/i18n/text.rs` unless noted):
  - every key is UPPER_SNAKE (`keys_are_english_upper_snake`);
  - every key the code uses has an English and a Korean line
    (`every_key_the_code_names_is_in_english_and_korean`, scans the source);
  - every table has every English key (`every_table_has_every_english_key`);
  - every translation keeps the English placeholders
    (`every_translation_keeps_the_english_placeholders`);
  - no key appears twice in a table (`no_key_is_in_a_table_twice`, see §5);
  - every key in `missables.tsv` is translated (`every_text_of_the_table_is_translated`,
    `src/guide/missables.rs`).
- **Adding text:** write `tr!("NEW_KEY")` in code, then add `NEW_KEY \t text` to `en.tsv`, `ko.tsv`
  and the other tables. The tests report anything missing.

## 4. Fonts

- **Panel (egui):** Malgun Gothic + Segoe UI Symbol. For `ja`, Yu Gothic is put first; for `zh-Hans`,
  Microsoft YaHei, only while that language is active (CJK fonts are tens of MB). After a language
  change the fonts are reinstalled on the next frame.
- **Overlay (GDI, Malgun Gothic):** Windows font linking fills in kana and simplified Chinese.

## 5. Per-language polish (2026-10-03)

- Each of the 12 languages was polished by one agent playing a speaker of that language (game UI
  translator and PC gamer), editing only its own table.
- Context given to each agent: a file listing, per key, the kind of UI element (button, card title,
  hint, error, console, map) and where the code uses it; and that language's official game text
  (`Mods\locale`).
- Shared rules:
  - keys, placeholders and `{g:…}` tokens stay unchanged;
  - numbers use a "Label: {count}" pattern so any count reads naturally;
  - phrasing must not break case endings, suffixes or particles after a name (German, Polish and
    Russian case inflection, Turkish suffixes, Korean particles);
  - the game's official terms take priority (for example the game's own words for stamina and
    cooldown in Korean, APC, Gram, Pobudzenie).
- Found during the pass: some keys generated from the same Korean source text collided (the Korean
  for "move" and for "code / password"). They were split into `LOAD_POSITION` and `PIN_CODE`, and the
  duplicate-key test was added.
