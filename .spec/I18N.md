# 다국어 (i18n)

모드는 **게임의 텍스트 언어 설정**을 그대로 따른다. 게임 옵션에서 언어를 바꾸면 몇 초 안에 모드도 바뀐다.

## 1. 언어 감지
- 게임 설정: `%LOCALAPPDATA%\HellIsUs\Saved\SaveGames\HellIsUsProfile.sav` 의 `TextCulture` (StrProperty, 예 `ko`).
  `AudioCulture` 는 음성 언어라 따로. GameUserSettings.ini 에는 없다.
- `i18n::follow_game()` — 패널 시작 때 한 번, 그 뒤 백업 스레드가 2초마다. 파일 수정 시각이 바뀔 때만 다시 읽음.
- 게임이 내는 12개: de en es fr it ja ko pl pt-BR ru tr zh-Hans. 표가 없는 문화권은 언어만(`pt-BR`→`pt`), 그다음 영어.

## 2. 게임 고유명사 (아이템·NPC·지역) — 게임의 번역 그대로
- `hiumod doctor locale` (또는 `doctor survey` 끝에 자동) → tools/survey `--locale`:
  - `Mods\locale\<culture>.tsv` — 게임 locres 전부: `namespace \t key \t text` (언어당 ~6,700줄, \n \t \ 이스케이프).
  - `Mods\locale\names.tsv` — 무엇이 어느 텍스트로 불리나:
    | 종류 | id | 출처 |
    |---|---|---|
    | item | 데이터 에셋 이름(소문자) | `Items/**/*_DA` 의 `ItemData.Name` (문자열 테이블 → 그 테이블의 namespace) |
    | npc | 블루프린트 클래스(소문자) | 퀵챗: `QuickChatSubjectPersistenceRuneComponent.Rune.SpeakerInfos.SpeakerName` · 대화: `ConversationRuneComponent.Rune.NamePayload.ContainedFacts[0]` → StringFactData.Description |
    | name | 이름 사실 에셋 | StoryUnits 의 `Track=Name` StringFactData (실명 등, 스토리 유닛별) |
    | region | 월드 | `Facts_Shared / Universal_Location_<World>` |
  - 문자열 테이블 텍스트의 locres namespace 는 TableId 경로가 아니라 **테이블의 TableNamespace** (`Items_Secrets_ST` → `Secrets_Items`).
  - 둘 다 게임 데이터라 커밋하지 않는다.
- NPC 이름: 처음 만났을 때 이름(예: 숨어 있는 정비공) → 주인공이 그 스토리 유닛의 실명 사실을 알게 되면 실명 (`i18n::set_known`, 엔진이 지식 읽을 때).
- 퀘스트 단서 갈래(`Quest01_Tania` 등): 갈래 이름 뒤쪽이 스토리 유닛 → 아는 이름 사실 중 가장 구체적인 것 (실명 우선),
  하나도 모르면 게임이 처음 보여 주는 가명(Dummy/Unknown) — 실명을 미리 알려 주지 않음. 장소처럼 이름이 하나뿐이면 그것.
- 선행·미스터리 제목, 장소: 게임이 아직 보여 주지 않은 건 문자열 테이블의 영어 원문으로 나옴 → en.tsv 에서 같은 키를
  찾아 현재 언어로 (`from_source`, namespace `UI_Secrets`·`Facts_*`).
- 아이템을 주지 않는 조사 지점(사실·태그만)은 게임에 이름이 없음 → "살펴볼 곳".
- 일본어 텍스트의 zero-width space(U+200B)는 지움.
- 없으면(조사 안 함) 클래스 이름으로 만든 이름 (`goals::pretty`, `item_label`).
- 퀘스트 이름은 원래 게임 메모리의 FText(현재 언어)라 그대로; 캐시 `quests.txt` 는 언어별 (`quests.<culture>.txt`, 한국어는 기존 이름).

## 3. 모드 자체 문구
- 코드는 한국어로 쓰고 감싼다: `tr!("다음 목표 ▶")`, `trf!("이 지역 {n}곳", n = here)`.
  - `trf!` 는 값마다 이름을 붙임 → 번역이 순서를 바꿔도 됨. 실행 시 채움(`i18n::fill`): `{name}`, `{name:spec}` (채움·정렬·폭·정밀도).
  - const 표의 문구(치트 이름, 수집 분류)는 보여 줄 때 `i18n::tr(c.label)`.
  - 문구 안의 고유명사(지역·인물·키스톤)는 직접 쓰지 않고 `{g:namespace/key}` — 게임 텍스트에서 그 언어로 채움
    (예 `{g:Facts_Shared/Universal_Location_Talju}` → 탈주 / Talju / タルジュ). 번역도 같은 토큰을 그대로 둔다.
  - 데이터 표의 문구(`assets/missables.tsv` 의 할 일)도 번역 표의 키 — `i18n::text()` 로 번역·채움. 테스트가 영어 줄 확인.
  - 상태·오류 메시지(게임 연결, 게이트, 치트 명령), 콘솔의 CLI 출력도 같은 방식. CLI 도 시작할 때 게임 언어를 따름.
  - 도움말(`help`)은 언어별 파일 `assets/i18n/help/<culture>.txt` (12개).
  - 로그 파일(hiumod.log)만 영어로 남김 — 개발 기록.
- 번역 표: `assets/i18n/<culture>.tsv` — `한국어 \t 번역`, 프로그램에 포함 (`text.rs` TABLES).
  게임의 12개 언어 모두 있음: en 은 직접 작성. 나머지 10개는 각 언어의 게임 공식 용어(림빅·키스톤·선행·지역명 등)를 Mods\locale 에서 찾아 번역.
  확인이 필요한 용어: APC (언어별 게임 표기 VAB·БТР·ZPT 등), Secret, 제작서, 게임에 없는 이름 (Vyssa 광산 등).
  한국어는 원문 그대로, 표에 없는 줄은 영어 → 그래도 없으면 한국어.
- 테스트가 지키는 것:
  - 모든 번역 표가 영어 표의 모든 줄을 자기 줄로 가진다 (`every_table_has_every_english_line_of_its_own`).
  - 모든 `tr!`/`trf!` 문자열에 영어 줄이 있다 (`every_wrapped_string_has_an_english_line` — 소스를 훑음).
  - 각 번역이 같은 자리표시자를 가진다.
- 새 문구 추가: 코드에 `tr!`/`trf!` → `assets/i18n/en.tsv` (와 다른 표)에 한 줄. 테스트가 빠진 걸 알려 준다.

## 4. 글꼴
- 패널(egui): 맑은 고딕 + Segoe UI Symbol. ja 는 Yu Gothic, zh-Hans 는 Microsoft YaHei 를 앞에 (그 언어일 때만 — CJK 글꼴은 수십 MB).
  언어가 바뀌면 다음 프레임에 다시 설치.
- 오버레이(GDI, 맑은 고딕): Windows 글꼴 연결이 가나·간체를 채운다.
